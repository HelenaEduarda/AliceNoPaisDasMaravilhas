# Alice no País das Maravilhas

Esse é um projeto desenvolvido para uma atividade da faculdade, utilizando HTML e CSS.
Vale ressaltar que é meu primeiro, então está meio tosco.

## Sobre o projeto

O site foi criado com o tema **Alice no País das Maravilhas**.

A ideia é mostrar um pouco sobre a história de Alice, alguns dos principais momentos da sua jornada e os personagens que aparecem durante a aventura.

Escolhi fazer o site com cores mais escuras e azuladas para deixar o visual mais misterioso e combinar com o tema.

## Páginas

O site possui 3 páginas:

* **Início:** apresentação do tema e do site.
* **Jornada:** mostra alguns dos principais momentos da jornada de Alice.
* **Personagens:** apresenta alguns personagens da história.

## Tecnologias utilizadas

* HTML
* CSS

## Objetivo

O objetivo do projeto é colocar em prática os conteúdos estudados em aula, como estruturação de páginas HTML, utilização de tags, links, classes, IDs e estilização com CSS.
